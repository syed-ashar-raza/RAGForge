# RAGForge Test Knowledge

RAGForge is a local retrieval augmented generation system.

Its pipeline consists of document ingestion, text normalization, chunking, embedding generation, vector-style similarity retrieval, and grounded answer generation.

RAGForge supports PDF, TXT, and Markdown documents.

The default embedding model is sentence-transformers/all-MiniLM-L6-v2.

The system uses chunk overlap to preserve context between adjacent chunks.

Retrieved sources are returned with answers so users can inspect where information came from.

RAGForge is designed as a professional AI engineering portfolio project demonstrating retrieval augmented generation, APIs, embeddings, document processing, and grounded generation.
